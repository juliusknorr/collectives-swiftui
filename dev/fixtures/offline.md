# Offline guide

1. Open this page in the native app while connected.
2. Disconnect the app from the network and edit this paragraph.
3. Quit and reopen the app. Your draft should still be present.
4. Switch accounts, then return to Alice. The draft should belong to Alice.
5. Reconnect and sync. Reload this page in the browser to verify the result.
